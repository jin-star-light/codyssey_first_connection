## 1. 과제 분석

**사용자 요청**

**진행 내용**

- 이전 과제 코드를 검토해 Codyssey OpenAI 호환 API의 인증 방식과 환경변수 이름을 재사용하기로 했다.

## 2. 서비스 주제 결정

**사용자 요청**

> 날짜를 입력하면 그 날짜 제철 과일추천으로 컨셉잡아줘.

**결정 내용**

- 서비스명: 제철한입
- 타겟: 건강한 간식과 장보기에 관심 있는 일반 사용자
- 입력: 날짜
- 출력: 한국 국내 유통 기준 제철 과일 3종
- 세부 정보: 제철 이유, 맛·영양, 고르는 법, 보관법, 간단한 레시피

## 3. AI 구조 설계

AI만으로 과일을 선택하면 결과가 흔들릴 수 있어 `월별 고정 후보 + AI 설명 생성`의 혼합 방식을 선택했다.

1. Python 서버가 날짜를 검증한다.
2. 월별 데이터에서 과일 후보 3종을 고른다.
3. AI는 후보를 바꾸지 않고 설명만 생성한다.
4. JSON 형식이 잘못되면 한 번 교정한다.
5. 형식 복구가 실패하면 서버의 기본 정보를 표시한다.

## 4. 화면 및 오류 UX 설계

- 홈, AI 추천, 제철 캘린더, 이용 안내의 4개 섹션 구성
- 모바일 1열, 태블릿 2열, 데스크톱 3열 결과 카드
- 빈 날짜, API 오류, 20초 타임아웃 안내
- 키보드 메뉴 조작, 포커스 표시, `aria-live` 상태 안내
- 실제 API 키는 Python 환경변수에서만 사용

## 5. 구현

- `api/seasonal_data.py`: 12개월 제철 후보와 기본 설명
- `api/recommend.py`: 날짜 검증, AI 호출, JSON 검증·교정, 오류 응답
- `index.html`: 네 섹션과 입력·결과 영역
- `css/style.css`: 마켓 스타일과 반응형 레이아웃
- `js/app.js`: 메뉴, fetch, 로딩·오류 상태, 안전한 DOM 렌더링
- `README.md`, `docs/service-plan.md`: 실행·배포·보안·기획 문서

사용자 요청에 따라 자동화 테스트 파일은 만들지 않고 구문 검사와 수동 동작 확인을 수행했다.

## 6. 오류 발견과 수정

- 실행 환경에서 `python` 명령을 찾지 못해 Codex 번들 Python의 절대 경로로 검증했다.
- 로컬 Python에 `requests`가 없어 오프라인 검증용 `pip._vendor.requests` 대체 import를 추가했다.
- 360px 화면에서 Hero 장식이 가로 스크롤을 만들던 원인을 실제 요소 너비로 추적하고 장식 영역의 overflow만 잘라 수정했다.
- 누락된 favicon 요청의 404를 인라인 SVG 아이콘으로 제거했다.
