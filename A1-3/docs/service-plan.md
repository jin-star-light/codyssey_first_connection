# 제철한입 서비스 기획서

## 1. 서비스 개요

- 서비스명: 제철한입
- 목적: 날짜를 기준으로 제철 과일을 쉽고 재미있게 고르도록 돕는다.
- 타겟 사용자: 건강한 간식과 장보기에 관심 있지만 과일의 제철 시기를 외우기 어려운 일반 사용자
- 핵심 가치: 검색을 반복하지 않고 날짜 한 번 입력해 과일 3종의 선택·보관·활용 정보를 얻는다.

## 2. 페이지·섹션 구성

단일 페이지 안에서 메뉴로 다음 네 섹션을 이동한다.

1. 홈: 서비스 소개, 추천 기능 바로가기, 핵심 장점
2. AI 추천: 날짜 입력, 로딩·오류 안내, 과일 3종 결과
3. 제철 캘린더: 1월부터 12월까지 대표 과일
4. 이용 안내: 추천 기준, AI 정보 주의사항, FAQ

모바일에서는 접이식 메뉴를 사용하고, 태블릿과 데스크톱에서는 가로 메뉴를 사용한다.

## 3. 핵심 기능

### 입력

- 필수값: `YYYY-MM-DD` 형식의 실제 날짜
- 사용자는 기본값으로 오늘 날짜를 확인하고 다른 날짜로 변경할 수 있다.

### 처리

1. 프론트엔드가 빈 입력을 먼저 확인한다.
2. Python API가 실제 날짜인지 다시 검증한다.
3. 입력한 달에 맞는 한국 국내 유통 기준 과일 후보 3종을 고정 데이터에서 선택한다.
4. AI에는 선택된 후보만 전달해 제철 이유와 실용 정보를 생성하게 한다.
5. AI JSON이 잘못되면 한 번 교정하고, 그래도 형식이 맞지 않으면 기본 정보를 사용한다.

### 출력

과일 3종마다 다음 값을 표시한다.

- 과일명과 이모지
- 제철 이유
- 맛과 일반적인 영양 특징
- 잘 고르는 법
- 보관법
- 간단한 레시피

제철 시기는 품종, 산지와 기후에 따라 달라질 수 있다는 안내를 함께 표시한다.

## 4. AI 기능의 사용자 가치

고정 데이터만 보여 주는 달력보다 자연스럽고 실용적인 설명을 제공하면서, AI가 제철 과일 자체를 임의로 고르지 않게 제한해 결과의 일관성을 높인다. 사용자는 장보기 직전에 필요한 정보까지 한 화면에서 얻을 수 있다.

## 5. 실패 처리 기준

- 빈 입력: `추천받을 날짜를 먼저 선택해 주세요.`
- 잘못된 날짜: `올바른 날짜를 선택해 주세요.`
- 서버 환경변수 누락: 서비스 설정이 완료되지 않았다는 안내
- AI 인증·쿼터·네트워크 오류: 잠시 후 다시 시도하라는 안내
- AI 응답 형식 오류: 한 번 교정 후 기본 제철 정보를 표시하고 그 사실을 안내
- 20초 이상 지연: 브라우저에서 요청을 취소하고 재시도 안내
- 알 수 없는 오류: 상세 내부 정보 없이 안전한 한국어 메시지 표시

API 키와 인증 헤더는 오류 메시지와 로그에 포함하지 않는다.

## 6. 반응형·접근성 기준

- 360px 모바일: 메뉴 접기, 결과 카드 1열
- 768px 태블릿: 가로 메뉴, 결과 카드 2열
- 1280px 데스크톱: 결과 카드 3열, 캘린더 4열
- 모든 주요 조작은 키보드로 접근할 수 있어야 한다.
- 포커스 표시, 충분한 색상 대비, 최소 44px 조작 영역을 제공한다.
- 로딩·성공·실패 메시지는 `aria-live` 영역으로 전달한다.
- 사용자가 모션 감소를 설정하면 불필요한 애니메이션을 줄인다.

## 7. 보안·운영 기준

- 실제 키는 Vercel과 로컬 터미널의 `COPA_API_KEY` 환경변수로만 관리한다.
- 프론트엔드는 `/api/recommend`만 호출하고 AI 서비스 주소나 키를 다루지 않는다.
- 요청 중 추천 버튼을 잠가 중복 호출을 줄인다.
- `.env`, `.vercel`, Python 캐시는 Git에서 제외한다.

## 8. 완료 기준

- 네 섹션과 메뉴 이동이 동작한다.
- 정상 날짜 입력에서 과일 3종이 표시된다.
- Python Serverless Function이 AI API를 호출한다.
- 빈 입력, API 오류, 타임아웃을 사용자에게 안내한다.
- 모바일과 데스크톱에서 레이아웃이 정상이다.
- README에 소개, 기술 스택, 실행·배포 방법, 환경변수 설정과 배포 URL 항목이 있다.
- 실제 API 키가 코드, 문서, 화면에 노출되지 않는다.
