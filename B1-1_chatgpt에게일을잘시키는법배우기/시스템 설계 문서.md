
# 문서2. 업무 자동화 과업 정의

> 본 문서는 `녹취록 기반 회의록 요약` 업무 자동화 과업의 필수 구성 요소를 정의한 문서이다.

---

## 1. 선택한 업무 자동화 과업

### 과업명

```text
녹취록 기반 회의록 요약
```

### 과업 설명

본 과업은 회의, 강의, 인터뷰, 상담, 업무 대화 등의 녹취록 TXT를 입력하면 핵심 내용, 결정사항, 공지사항, 해야 할 일, 일정, 확인 필요 사항을 구조화된 회의록 형태로 요약하는 업무 자동화 과업이다.

---

## 2. 타겟 사용자

| 구분     | 내용                                                |
| ------ | ------------------------------------------------- |
| 타겟 사용자 | 녹취록을 정리하려는 모든 사용자                                 |
| 사용 상황  | 회의, 강의, 인터뷰, 상담, 업무 대화 등의 녹취록을 빠르게 정리해야 하는 경우     |
| 사용자 목적 | 긴 녹취록에서 중요한 내용을 빠르게 파악하고, 실행해야 할 일과 일정을 놓치지 않기 위함 |

---

## 3. 입력 데이터 형태

| 구분        | 내용                                          |
| --------- | ------------------------------------------- |
| 입력 데이터 형식 | TXT                                         |
| 입력 내용     | 음성 녹음본을 텍스트로 변환한 녹취록                        |
| 포함 가능 정보  | 회의 주제, 날짜, 참석자, 화자, 발화 내용, 논의 내용, 일정, 할 일 등 |

---

## 4. 출력 규격

> LLM은 입력된 녹취록을 바탕으로 아래 항목에 맞춰 결과를 출력한다.

| 출력 항목          | 설명                                  |
| -------------- | ----------------------------------- |
| 핵심 내용          | 녹취록 전체에서 가장 중요한 내용을 3~5개로 요약        |
| 결정사항           | 회의나 대화에서 확정된 내용 정리                  |
| 공지사항/공유 정보     | 참석자에게 전달된 안내, 공지, 참고사항 정리           |
| 변치 않는 사실/핵심 정보 | 원문에 등장한 객관적 사실, 규칙, 배경지식 정리         |
| 해야 할 일         | 이후 실행해야 하는 업무 또는 Action Items 정리    |
| 일정             | 날짜, 시간, 마감일, 예정된 이벤트 정리             |
| 리스크/확인 필요      | 불명확하거나 추가 확인이 필요한 내용 정리             |
| AI가 되물어야 할 질문  | 업무 실행에 필요한 정보가 부족하거나 모호할 때 확인 질문 정리 |

---

## 5. 입력 템플릿

```txt
[목적]
아래 녹취록 TXT를 바탕으로 회의록 요약 보고서를 작성해줘.

[회의/녹음 상황]
- 회의 또는 녹음 주제: [여기에 주제 입력]
- 당시 상황: [예: 촬영 준비 회의 / 과제 제출 공지 / 강의 내용 정리 / 워크숍 준비 논의]
- 날짜: [날짜 입력 / 미상]
- 참석자 또는 화자: [참석자 입력 / 미상]

[입력 데이터 형태]
TXT 형식의 녹취록

[출력 규격]
1. 핵심 내용
2. 결정사항
3. 공지사항/공유 정보
4. 변치 않는 사실/핵심 정보
5. 해야 할 일
6. 일정
7. 리스크/확인 필요
8. AI가 되물어야 할 질문

[출력 원칙]
- 업무용 회의록 문체로 간결하고 객관적으로 작성한다.
- 원문에 없는 내용은 추측하지 않는다.
- 불확실한 내용은 “확인 필요”로 표시한다.
- 담당자나 마감일이 언급되지 않은 경우 “미상”으로 표시한다.
- 일정이 언급되지 않은 경우 “언급 없음”으로 표시한다.
- 중복 표현은 정리하되 의미는 바꾸지 않는다.
- 표와 bullet을 활용해 보기 쉽게 작성한다.

[부족 정보 처리]
- 녹취록 안에 업무 실행에 필요한 정보가 부족하거나 모호한 경우, 임의로 보완하지 않는다.
- 필요한 경우 “AI가 되물어야 할 질문” 항목을 추가하여 확인 질문을 작성한다.
- 확인 질문은 최대 30개까지 작성할 수 있다.
- 단, 불필요하게 질문을 늘리지 말고 실제 업무 수행에 필요한 질문만 작성한다.

[녹취록 TXT]
여기에 녹취록 텍스트를 붙여넣는다.
```
