# 문서7. 실행 로그 및 문맥 유지 검증

> 본 문서는 `녹취록 기반 회의록 요약` 시스템이 10턴 동안 이전 대화의 조건을 유지하고, 중간 변경 사항만 반영하는지 검증하기 위한 실행 로그이다.

---

## 7-1. 시나리오 설명

본 실행 로그는 `녹취록 기반 회의록 요약` 과업에서 AI가 여러 턴에 걸쳐 추가되는 회의 내용을 얼마나 안정적으로 반영하는지 확인하기 위한 테스트이다.

테스트 시나리오는 팀 워크숍 준비 회의이다.
초기 입력에서는 워크숍 목적, 기본 일정, 장소, 참석 인원 등이 제시되고, 이후 턴에서는 준비물, 예산, 장소 후보, 참석 인원 변경 가능성, 식이 제한, 시간 변경 가능성, 예산 상한 검토 등이 순차적으로 추가된다.

AI는 각 턴에서 다음 조건을 유지해야 한다.

* 이전 턴에서 확정된 정보는 유지한다.
* 새로 추가되거나 변경된 정보만 반영한다.
* 확정된 내용과 미확정 내용을 구분한다.
* 지정된 8개 출력 항목을 유지한다.
* 원문에 없는 조언이나 추천을 추가하지 않는다.
* 모호하거나 부족한 정보는 “확인 필요”, “미상”, “언급 없음”으로 표시한다.

이번 실행 로그는 사용자 입력 5회와 GPT-5 답변 5회를 각각 하나의 턴으로 계산하여 총 10턴으로 구성하였다.

| 턴 번호 | 화자    | 내용 요약                          |
| ---: | ----- | ------------------------------ |
|   1턴 | 사용자   | 초기 워크숍 준비 회의 녹취록 입력            |
|   2턴 | GPT-5 | 초기 회의록 요약 및 문맥 유지 검증           |
|   3턴 | 사용자   | 준비물, 고기 구매 담당자, 예산 20만 원 기준 추가 |
|   4턴 | GPT-5 | 준비물과 예산 조건 반영                  |
|   5턴 | 사용자   | 장소 후보와 참석 인원 변경 가능성 추가         |
|   6턴 | GPT-5 | 홍대 기본안과 강남 대체 후보 구분            |
|   7턴 | 사용자   | 식이 제한과 강남 선택 시 시간 변경 가능성 추가    |
|   8턴 | GPT-5 | 식이 제한과 일정 변경 가능성 반영            |
|   9턴 | 사용자   | 예산 상한 25만 원 검토 및 최종 종합 요청      |
|  10턴 | GPT-5 | 전체 내용을 종합한 최종 회의록 작성           |

---

## 7-2. 10턴 이상 대화 전문

아래는 실제 실행 로그 전문이다.
각 사용자 입력과 GPT-5 답변을 각각 하나의 턴으로 계산하여 1턴부터 10턴까지 번호를 부여하였다.

---

## 1턴 사용자

```txt
[목적]
아래 녹취록 TXT를 바탕으로 회의록 요약 보고서를 작성해줘.

[회의/녹음 상황]
- 회의 또는 녹음 주제: 팀 워크숍 준비 회의
- 당시 상황: 워크숍 준비 논의
- 날짜: 미상
- 참석자 또는 화자: 사용자1, 사용자2, 사용자3

[입력 데이터 형태]
TXT 형식의 녹취록

[출력 규격]
1. 핵심 내용
2. 결정사항
3. 공지사항/공유 정보
4. 변치 않는 사실/핵심 정보
5. 해야 할 일
6. 일정
7. 리스크/확인 필요
8. AI가 되물어야 할 질문

[출력 원칙]
- 업무용 회의록 문체로 간결하고 객관적으로 작성한다.
- 원문에 없는 내용은 추측하지 않는다.
- 불확실한 내용은 “확인 필요”로 표시한다.
- 담당자나 마감일이 언급되지 않은 경우 “미상”으로 표시한다.
- 일정이 언급되지 않은 경우 “언급 없음”으로 표시한다.
- 중복 표현은 정리하되 의미는 바꾸지 않는다.
- 표와 bullet을 활용하되, 지정된 8개 출력 항목 외 새로운 상위 항목은 만들지 않는다.
- 핵심 내용은 반드시 bullet 3개만 작성한다.
- 기본 정보, 프로그램 구성, 참석 인원 현황, 장소 현황, 식이 제한 사항, 예산 현황 같은 별도 섹션을 만들지 않는다.

[부족 정보 처리]
- 녹취록 안에 업무 실행에 필요한 정보가 부족하거나 모호한 경우, 임의로 보완하지 않는다.
- 필요한 경우 “AI가 되물어야 할 질문” 항목을 추가하여 확인 질문을 작성한다.
- 확인 질문은 최대 30개까지 작성할 수 있다.
- 단, 불필요하게 질문을 늘리지 말고 실제 업무 수행에 필요한 질문만 작성한다.

[녹취록 TXT]
사용자1:
이번 팀 워크숍 준비 회의 시작할게요. 원래는 다음 주 금요일 오후 2시에 홍대 공유오피스에서 진행하는 걸로 이야기했었죠. 목적은 새 프로젝트 시작 전에 팀원들끼리 역할을 맞추고, 간단한 식사랑 아이스브레이킹까지 같이 하는 거예요. 우선 큰 방향은 회의 1시간, 식사 1시간, 자유 네트워킹 30분 정도로 생각하고 있습니다.

사용자2:
네, 참석 인원은 지난번 기준으로 10명 정도라고 보면 될까요? 제가 기억하기로는 기획팀 4명, 디자인팀 3명, 영상팀 3명이 참석한다고 했던 것 같아요. 다만 영상팀에서 한 명이 촬영 일정이 겹칠 수도 있다고 했으니, 정확한 인원은 나중에 다시 확인해야 할 것 같습니다.
```

## 2턴 GPT-5 답변

## 회의록 요약

### 1. 핵심 내용

* 팀 워크숍은 새 프로젝트 시작 전 역할 조율, 식사, 아이스브레이킹을 목적으로 논의되었다.
* 기존 기본안은 다음 주 금요일 오후 2시, 홍대 공유오피스에서 진행하는 것이다.
* 참석 인원은 10명 기준으로 논의되었으나, 영상팀 1명의 참석 여부는 확인이 필요하다.

### 2. 결정사항

| 항목       | 내용                          |
| -------- | --------------------------- |
| 워크숍 목적   | 역할 조율, 식사, 아이스브레이킹          |
| 진행 구성    | 회의 1시간, 식사 1시간, 자유 네트워킹 30분 |
| 기본 일정/장소 | 다음 주 금요일 오후 2시, 홍대 공유오피스    |

### 3. 공지사항/공유 정보

* 워크숍은 새 프로젝트 시작 전 팀원 간 역할을 맞추기 위한 목적이 있다.
* 기존 논의안은 홍대 공유오피스에서 오후 2시에 진행하는 것이다.
* 참석 인원은 기획팀 4명, 디자인팀 3명, 영상팀 3명으로 총 10명 기준이다.

### 4. 변치 않는 사실/핵심 정보

* 회의 주제는 팀 워크숍 준비이다.
* 워크숍 목적은 역할 조율, 식사, 아이스브레이킹이다.
* 영상팀 1명은 촬영 일정으로 참석 여부가 불확실하다.

### 5. 해야 할 일

| 해야 할 일            | 담당자 | 마감일 |
| ----------------- | --- | --- |
| 영상팀 1명 참석 여부 확인   | 미상  | 미상  |
| 정확한 워크숍 날짜 확인     | 미상  | 미상  |
| 홍대 공유오피스 예약 상태 확인 | 미상  | 미상  |

### 6. 일정

| 일정    | 날짜/시간          | 비고                |
| ----- | -------------- | ----------------- |
| 팀 워크숍 | 다음 주 금요일 오후 2시 | 기본안, 정확한 날짜 확인 필요 |

### 7. 리스크/확인 필요

* “다음 주 금요일”의 정확한 날짜가 언급되지 않았다.
* 영상팀 1명의 참석 여부가 확정되지 않았다.
* 홍대 공유오피스 예약 여부는 확인이 필요하다.

### 8. AI가 되물어야 할 질문

* 다음 주 금요일의 정확한 날짜는 언제인가요?
* 영상팀 1명의 참석 가능 여부는 언제 확인할 수 있나요?
* 홍대 공유오피스 예약은 확정되었나요?

### 문맥 유지 검증

| 검증 항목                 | PASS/FAIL | 근거                               |
| --------------------- | --------- | -------------------------------- |
| 이전 대화를 유지했는가?         | PASS      | 첫 턴이므로 입력된 기본 조건을 반영함            |
| 조건 변경사항만 변경했는가?       | PASS      | 아직 변경 조건 없음                      |
| 확정/미확정 정보를 구분했는가?     | PASS      | 영상팀 1명 참석 여부와 정확한 날짜를 확인 필요로 구분함 |
| 출력 템플릿이 유지되었는가?       | PASS      | 지정된 8개 항목을 모두 사용함                |
| 원문에 없는 내용을 추가하지 않았는가? | PASS      | 원문에 나온 정보만 정리함                   |

**최종 판정:** PASS

## 3턴 사용자

```txt
아래 내용은 이전 녹취록에 이어지는 추가 발화입니다.

이전 대화에서 확정된 조건은 유지하고, 이번 턴에서 새로 추가되거나 변경된 내용만 반영해줘.
지정된 8개 출력 항목을 그대로 유지해줘.
새로운 상위 항목은 만들지 마.
핵심 내용은 bullet 3개만 작성해줘.
원문에 없는 조언이나 추천은 추가하지 마.

[추가 녹취록 TXT]
사용자3:
준비물은 일단 고기랑 음료, 종이컵, 일회용 접시 정도가 필요할 것 같아요. 식사를 간단히 하려면 고기는 넉넉히 준비해야 할 것 같은데, 어떤 고기를 살지는 아직 정하지 않았습니다. 음료도 탄산이랑 물 정도로 생각했는데, 커피나 주스까지 포함할지는 결정이 필요합니다.

사용자1:
좋아요. 일단 고기 구매는 사용자2가 맡아주세요. 음료는 담당자를 아직 정하지 말고 보류합시다. 예산은 전체 준비물 기준으로 20만 원 안에서 맞추는 걸로 생각해 주세요. 다만 장소 대여비는 별도라서 이 예산에는 포함하지 않습니다. 고기 종류, 음료 종류, 정확한 수량은 아직 확정하지 않은 상태로 기록해 주세요.
```

* 고기 종류, 음료 종류, 정확한 수량, 음료 담당자는 아직 확정되지 않았다.

### 3. 공지사항/공유 정보

* 준비물로 고기, 음료, 종이컵, 일회용 접시가 필요하다고 언급되었다.

### 4. 변치 않는 사실/핵심 정보

* 고기 구매 담당자는 사용자2이다.
* 준비물 예산 기준은 20만 원이다.
* 고기 종류, 음료 종류, 정확한 수량은 아직 확정되지 않았다.

* 음료 담당자는 누구로 지정할까요?
* 준비물 수량은 참석 인원 기준 몇 명으로 계산할까요?
