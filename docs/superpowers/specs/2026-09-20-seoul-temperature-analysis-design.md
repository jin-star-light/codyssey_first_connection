# 2025년 서울 일별 기온 변화 분석 설계

## 1. 목적

`m1-1/M1-1. subject.md`의 시계열 분석 과제를 충족하는 재현 가능한 분석 결과물을 만든다. 분석 대상은 2025년 서울의 일별 평균·최고·최저기온이며, 기온의 연간 흐름과 계절성, 급격한 변화, 일교차를 일상적인 언어로 설명한다.

완료 결과물은 분석 코드, 원본 데이터, 네 개 이상의 시각화, Markdown 리포트, 실행 안내, 의존성 목록과 검증 테스트를 포함한다.

## 2. 데이터

- 출처: Open-Meteo Historical Weather API
- 위치: 서울 중심부 좌표(위도 37.5665, 경도 126.9780)
- 기간: 2025-01-01부터 2025-12-31까지
- 시간대: `Asia/Seoul`
- 단위: 섭씨(°C)
- 필드: 날짜, 일평균기온, 일최고기온, 일최저기온
- 예상 관측치: 365개

API 응답을 `m1-1/data/seoul_weather_2025.csv`에 저장해 분석 실행의 재현성과 결과 검토 가능성을 확보한다. 데이터 출처와 Open-Meteo 및 기반 재분석 자료의 출처 표시 조건을 리포트와 README에 명시한다.

## 3. 분석 질문

1. 2025년 서울 기온은 한 해 동안 어떤 흐름과 계절성을 보였는가?
2. 가장 덥고 추운 날은 언제이며 월별·계절별 평균기온 차이는 어느 정도인가?
3. 전날 대비 평균기온이 가장 크게 오르거나 내린 시기는 언제인가?
4. 일교차는 월별로 어떻게 달라지는가?

## 4. 처리 및 분석 방법

### 데이터 검증과 정제

수집 직후 다음 조건을 검사한다.

- 날짜가 중복 없이 오름차순인지 확인한다.
- 2025년의 365일이 모두 존재하는지 확인한다.
- 평균·최고·최저기온이 숫자이며 `최저 <= 평균 <= 최고`인지 확인한다.
- 결측치의 개수와 위치를 기록한다.

결측치가 있으면 연속 이틀 이하의 짧은 공백만 시간축 선형 보간한다. 그보다 긴 공백은 자동 보정하지 않고 분석을 중단해 데이터 문제를 드러낸다. 이상치는 IQR 기준으로 탐지하되, 실제 폭염·한파일 수 있으므로 삭제하지 않고 극한기온 후보로 표시한다.

### 파생 지표

- 7일 이동평균: 단기 노이즈를 줄인 기온 흐름
- 일별 변화량: 당일 평균기온에서 전날 평균기온을 뺀 값
- 일교차: 일최고기온에서 일최저기온을 뺀 값
- 월별 통계: 평균·최고·최저기온과 평균 일교차
- 계절별 통계: 봄(3~5월), 여름(6~8월), 가을(9~11월), 겨울(12월 및 1~2월)

## 5. 시각화

모든 이미지는 `m1-1/images`에 PNG로 저장하며 축, 단위, 범례와 출처를 명확히 표시한다.

1. `01_annual_temperature_trend.png`: 일평균기온과 7일 이동평균을 함께 표시한 연간 추이
2. `02_monthly_temperature.png`: 월별 평균 최고·평균·최저기온 비교
3. `03_daily_temperature_change.png`: 전날 대비 평균기온 변화량과 큰 변화 시점 강조
4. `04_monthly_diurnal_range.png`: 월별 평균 일교차 비교

## 6. 결과물 구조

```text
m1-1/
├── M1-1. subject.md
├── README.md
├── REPORT.md
├── analysis.py
├── requirements.txt
├── data/
│   └── seoul_weather_2025.csv
├── images/
│   ├── 01_annual_temperature_trend.png
│   ├── 02_monthly_temperature.png
│   ├── 03_daily_temperature_change.png
│   └── 04_monthly_diurnal_range.png
└── tests/
    └── test_analysis.py
```

`analysis.py`는 데이터 수집, 검증, 파생 지표 계산, 요약 통계 출력과 이미지 생성을 담당한다. 기본 실행에서는 이미 저장된 CSV를 사용하고, 명시적인 `--refresh` 옵션을 사용했을 때만 API에서 데이터를 다시 내려받는다.

## 7. 리포트 구성

`REPORT.md`는 다음 내용을 포함한다.

1. 분석 주제와 선정 이유
2. 네 가지 분석 질문
3. 데이터 출처, 기간, 컬럼, 품질 확인과 정제 기준
4. 적용한 시계열 분석 기법과 선택 이유
5. 네 개의 시각화와 각 그래프 설명
6. 세 개 이상의 인사이트
7. 결론과 한계
8. AI 사용 작업, 사용 이유, 검증 방법

각 인사이트는 `관찰(Fact)`과 `해석(Hypothesis)`을 구분한다. 관찰에는 날짜, 온도, 변화량 같은 계산된 수치를 넣고, 해석은 데이터만으로 인과관계를 확정할 수 없음을 명시한다.

## 8. 오류 처리와 재현성

- 네트워크 또는 API 오류는 원인과 재실행 방법을 포함한 메시지로 종료한다.
- 응답 스키마가 예상과 다르면 불완전한 CSV를 저장하지 않는다.
- 저장된 CSV가 검증을 통과하지 못하면 그래프를 만들지 않는다.
- Matplotlib의 비대화형 백엔드를 사용해 GUI가 없는 환경에서도 이미지를 생성한다.
- 난수에 의존하는 분석은 사용하지 않는다.
- `requirements.txt`에 직접 사용하는 패키지 버전 범위를 기록한다.

## 9. 검증 기준

자동 테스트는 다음을 확인한다.

- API 응답을 분석용 표로 변환하는 과정
- 중복 날짜, 긴 결측 구간, 잘못된 기온 순서의 거부
- 이동평균, 변화량, 일교차 계산
- 월별·계절별 집계 결과
- 네 개의 이미지 파일 생성

최종 검증에서는 새 환경을 가정한 설치·실행 명령, 전체 테스트, 데이터 개수, 이미지 링크와 리포트의 필수 섹션을 확인한다.

## 10. 범위와 한계

이 분석은 서울 중심 좌표에 대한 격자형 재분석 자료를 사용하므로 특정 관측소의 실측값과 다를 수 있다. 2025년 한 해만 분석하므로 장기적인 기후변화를 판단하지 않는다. 급격한 기온 변화의 원인을 날씨 시스템이나 사회적 사건으로 단정하지 않으며, 원인 확인에는 별도의 기상 자료가 필요하다고 명시한다.
