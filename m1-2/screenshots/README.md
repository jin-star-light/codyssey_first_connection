# 제출용 스크린샷 체크리스트

실제 배포 후 개인 키나 Firebase 콘솔의 비밀값이 보이지 않도록 촬영합니다.

- [ ] Vercel 공개 화면: 학습 요약, AI 채팅, 대화 기록, 데이터 관리 영역이 한 화면에 보이게 촬영
- [ ] 데이터 CRUD: 새 기록을 저장한 뒤 목록과 요약이 갱신된 화면 촬영
- [ ] AI 기능: 학습 데이터에 근거한 질문과 답변, 저장된 대화 제목이 함께 보이게 촬영
- [ ] FastAPI 문서: Render의 `/docs`에서 필수 API 엔드포인트가 보이게 촬영
- [ ] Firebase Firestore: `data`, `conversations` 컬렉션과 저장 문서가 보이되 서비스 계정 키는 보이지 않게 촬영
